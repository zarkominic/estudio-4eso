Qué es una ecuación de segundo grado

Es una ecuación donde la incógnita aparece al cuadrado, y se puede escribir así:

$$ax^2 + bx + c = 0 \qquad (a \neq 0)$$

Antes de hacer nada, pásalo todo a un lado hasta que quede igualado a cero. Luego lee a, b y c con su signo.

Leer a, b y c

$2x^2 - 3x - 5 = 0$

a = 2 · b = −3 · c = −5

El signo va pegado al número. Olvidarlo es el fallo que más ejercicios tira.

La fórmula y el discriminante

Sirve para todas:

$$x = \frac{-b \pm \sqrt{\Delta}}{2a} \qquad \Delta = b^2 - 4ac$$

El discriminante Δ te dice cuántas soluciones hay antes de calcularlas:

Δ > 0 → dos soluciones. Δ = 0 → una (doble). Δ < 0 → ninguna real, porque habría que hacer la raíz de un negativo.

Mueve a, b y c: la parábola corta el eje horizontal justo en las soluciones. Si no lo toca, Δ es negativo.

Incompletas: más rápido sin fórmula

Si falta c: factor común

$x^2 - 5x = 0 \Rightarrow x(x-5) = 0$

Un producto es cero si lo es alguno de los factores: x = 0 o x = 5.

Si falta b: despeja y haz la raíz

$x^2 - 49 = 0 \Rightarrow x^2 = 49$

$x = \pm 7$. Los dos signos: el −7 también vale.

Bicuadradas: un cambio y listo

Tienen x⁴ y x², pero ni x³ ni x. El truco es llamar t = x²:

  1. $x^4 - 13x^2 + 36 = 0$ → con t = x²: $t^2 - 13t + 36 = 0$.
  2. Resuelves en t: t = 4 y t = 9.
  3. Deshaces el cambio: x² = 4 → x = ±2; x² = 9 → x = ±3.
  4. Cuatro soluciones: −3, −2, 2 y 3.

Si alguna t sale negativa, esa no da soluciones: ningún número al cuadrado es negativo.

Con radicales: aísla, eleva y comprueba

Se deja la raíz sola en un lado, se elevan los dos lados al cuadrado y se resuelve. Pero hay un paso que no se puede saltar:

Hay que comprobar cada solución en la ecuación de partida. Al elevar al cuadrado pueden aparecer soluciones que no lo son.

$\sqrt{x+2} = x$ → $x + 2 = x^2$ → x = 2 y x = −1. Pero con x = −1: √1 = 1 y el otro lado da −1. No vale. La raíz cuadrada nunca da negativo.

Con fracciones: fuera los denominadores

Se multiplica todo por el denominador común, se resuelve y se descarta la solución que haga cero algún denominador.

$x + \dfrac{6}{x} = 5$ → multiplico por x → $x^2 + 6 = 5x$ → $x^2 - 5x + 6 = 0$ → x = 2 y x = 3. Ninguna es 0, así que valen las dos.

El error que más puntos cuesta

Dividir entre x

En $x^2 = 5x$ es tentador dividir entre x y dejar x = 5. Se pierde una solución.

El contraejemplo: sustituye x = 0 → 0² = 5·0 → 0 = 0. Cumple. Dividir entre x solo es legal si x ≠ 0, y justo el 0 era solución.

Qué hacer: pasar todo a un lado y sacar factor común. Nunca dividir entre algo que pueda valer cero.

Un ejemplo entero, paso a paso

La suma de un número positivo y su cuadrado es 42. ¿Cuál es?

  1. Planteo: x + x² = 42 → x² + x − 42 = 0.
  2. a, b, c: 1, 1 y −42.
  3. Δ = 1 − 4·1·(−42) = 1 + 168 = 169; √Δ = 13.
  4. x = (−1 ± 13)/2 → x = 6 y x = −7.
  5. Vuelvo al enunciado: pide un número positivo → 6. Comprobación: 6 + 36 = 42 ✓.
