Programación

Variables, condicionales, bucles, funciones y listas en Python, y cómo arreglar lo que falla. Teoría, código infinito que trazar y 14 preguntas.

Antes de leer nada, dos apuestas

No hace falta saberlo. Arriesga: equivocarte ahora hace que luego se te quede mejor.

Programar es dar órdenes en orden

Un programa es una lista de instrucciones que el ordenador ejecuta de arriba abajo, una a una, sin suponer nada. Esa última parte es la clave: el ordenador no adivina lo que querías decir.

Solo hay que dominar cuatro piezas, y con ellas se construye todo:

  • Variables: cajas donde guardar datos.
  • Condicionales: hacer una cosa u otra según el caso.
  • Bucles: repetir sin copiar y pegar.
  • Funciones: escribir algo una vez y usarlo muchas.

El «=» no es «igual»

En x = 5 el igual significa «guarda 5 en x». Por eso esto tiene sentido:

x = 5
x = x + 3

Primero se calcula la derecha (5+3) y el resultado se mete en x. Al final x vale 8.

Para comparar se usan dos iguales: ==.

Variables y tipos

Número enteroedad = 15 — sin comillas.
Decimalprecio = 3.5 — con punto, no con coma.
Textonombre = "Ana" — siempre entre comillas.
Verdadero o falsoaprobado = True — con mayúscula.

El error que más se repite al empezar: "5" + 3 da error. «5» entre comillas es texto, no número, y no se pueden sumar cosas de distinto tipo.

Pasa siempre con lo que escribe el usuario: input() devuelve texto. Hay que convertirlo: int(input()).

Condicionales: elegir camino

nota = 7

if nota >= 9:
    print("Sobresaliente")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

Se leen en orden y en cuanto una se cumple, las demás se saltan. Por eso importa ponerlas de más exigente a menos: si el elif nota >= 5 fuera primero, un 9 entraría ahí y nunca se vería «Sobresaliente».

Los dos puntosToda condición acaba en «:». Olvidarlos es el error número uno.
La sangría mandaLo indentado está dentro; lo que no, está fuera. En Python no hay llaves.
Comparaciones== igual, != distinto, >= mayor o igual.
Unir condicionesand las dos, or al menos una, not lo contrario.

Bucles: repetir sin copiar

for se usa cuando sabes cuántas veces:

for i in range(5):
    print(i)

Imprime 0, 1, 2, 3, 4. Cinco vueltas.

La trampa de range

range(5) empieza en 0 y no llega al 5.

range(2, 7) da 2, 3, 4, 5, 6: incluye el primero y excluye el último.

Si te piden contar del 1 al 10, es range(1, 11). Este despiste cuesta medio examen.

while se usa cuando no sabes cuántas veces, sino hasta cuándo:

i = 0
while i < 5:
    print(i)
    i = i + 1     # sin esta línea, no acaba nunca

El bucle infinito. Si nada hace que la condición se vuelva falsa, el programa se queda dando vueltas para siempre. Siempre que escribas un while, comprueba que algo lo acerca al final.

Funciones: escribirlo una vez

def area_rectangulo(base, altura):
    return base * altura

print(area_rectangulo(3, 4))   # 12
print(area_rectangulo(10, 2))  # 20

Escribes la fórmula una vez y la usas con los datos que quieras. Y si algún día está mal, se arregla en un solo sitio.

return devuelve el resultado para usarlo; print solo lo enseña por pantalla. No es lo mismo, y confundirlos es muy común.

Listas: muchos datos en una caja

notas = [7, 5, 9, 3]
print(notas[0])        # 7, el primero
print(len(notas))      # 4, cuántos hay
notas.append(10)       # añade al final

for n in notas:
    print(n)

Se empieza a contar en 0. El primero es notas[0] y el último de una lista de 4 es notas[3]. Pedir notas[4] da error.

Cuando algo falla

Programar es, sobre todo, arreglar lo que no funciona. Y hay un método:

  1. Lee el mensaje de error. Dice el tipo de fallo y la línea exacta. Casi nadie lo lee, y casi siempre lo dice todo.
  2. Traza el código a mano. Papel, y anota cuánto vale cada variable en cada línea.
  3. Imprime por el camino. Mete print() en varios puntos para ver dónde se tuerce.
  4. Cambia una cosa cada vez. Si cambias tres y funciona, no sabes cuál era.
ErrorQué significa
SyntaxErrorEstá mal escrito: faltan dos puntos, comillas o un paréntesis.
IndentationErrorLa sangría no cuadra.
NameErrorUsas una variable que no existe, o la has escrito mal.
TypeErrorMezclas tipos: texto con número.
IndexErrorPides una posición de la lista que no existe.

Un ejemplo entero, paso a paso

¿Qué imprime este programa?

total = 0
for i in range(1, 5):
    if i % 2 == 0:
        total = total + i
print(total)
  1. range(1, 5) da 1, 2, 3 y 4. El 5 no entra.
  2. i % 2 == 0 pregunta si el resto de dividir entre 2 es cero, o sea si es par.
  3. Vuelta a vuelta: con 1 no entra; con 2 sí, total = 2; con 3 no; con 4 sí, total = 6.
  4. Imprime 6. Y fíjate en que el print está FUERA del bucle: por eso imprime una sola vez, al final.
  5. Si estuviera dentro (indentado), imprimiría cuatro veces, una por vuelta. La sangría cambia el programa.

Ahora contigo

  1. range(3, 8) genera ? números.
  2. Si x = 4 y luego x = x * 3, x vale ?.
  3. En lista = [5, 8, 2], lista[1] vale ?.
  4. Para comparar si dos cosas son iguales se usa ?.
