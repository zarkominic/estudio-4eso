Robótica y sistemas de control

Entrada, proceso y salida; sensores y actuadores; lazo abierto y cerrado; y cómo se programa una placa Arduino. Teoría, ejercicios infinitos y 12 preguntas.

Qué es un sistema de control

Cualquier aparato que decide algo solo tiene tres partes. Siempre las mismas:

Entrada → recoge información (sensores).
Proceso → decide qué hacer (el controlador, la placa).
Salida → actúa sobre el mundo (actuadores).

Un robot no es más que eso con un programa dentro: percibe, decide y actúa.

Ejemplo: el riego automático

Entrada: un sensor de humedad en la tierra.

Proceso: la placa compara con el mínimo.

Salida: una electroválvula abre el agua.

Luz, sonido, y encender otro circuito más potente.

Lazo abierto y lazo cerrado

Lazo abierto: hace lo programado y no mira el resultado. Una tostadora con temporizador.

Lazo cerrado: mide lo que ha conseguido y corrige. A eso se le llama realimentación. Un termostato.

Prueba el simulador: la calefacción de una casa en invierno. Con lazo abierto se enciende a potencia fija; con lazo cerrado, un termostato la enciende y apaga para mantener 21 °C. Cambia el frío de fuera.

La placa Arduino

Es el «proceso»: un pequeño ordenador que lee sensores y mueve actuadores. Tiene:

14 pines digitales (0 a 13): solo entienden encendido o apagado, HIGH (5 V) o LOW (0 V).
6 pines analógicos (A0 a A5): leen tensiones que varían, y dan un número de 0 a 1023.

void setup() {          // se ejecuta UNA vez al encender
  pinMode(13, OUTPUT);  // el pin 13 será una salida
}

void loop() {           // se repite sin parar
  digitalWrite(13, HIGH);  // enciende
  delay(1000);             // espera 1000 ms = 1 s
  digitalWrite(13, LOW);   // apaga
  delay(1000);
}

Este es el «hola mundo» de Arduino: hace parpadear un LED cada segundo.

Programar un robot: leer, decidir, actuar

Cualquier programa de robot tiene esta forma dentro de loop():

int luz = analogRead(A0);     // 1. LEER el sensor
if (luz < 300) {              // 2. DECIDIR
  digitalWrite(13, HIGH);     // 3. ACTUAR: poca luz → enciende
} else {
  digitalWrite(13, LOW);
}

Así funciona una farola automática. El número 300 es el umbral: se ajusta probando.

El error que más puntos cuesta

Pensar que delay cuenta en segundos

delay(2) no espera dos segundos: espera dos milésimas. El LED parpadearía tan rápido que parecería siempre encendido.

El contraejemplo: para esperar 2 segundos hace falta delay(2000). Si en un examen te sale un parpadeo «que no se ve», casi seguro es esto.

Un ejemplo entero, paso a paso

Diseña una alarma: si el sensor de ultrasonidos detecta algo a menos de 20 cm, suena el zumbador.

  1. Entrada: sensor de ultrasonidos. Salida: zumbador en el pin 8.
  2. setup: pinMode(8, OUTPUT);
  3. loop, leer: calcular la distancia a partir del eco.
  4. Decidir: if (distancia < 20).
  5. Actuar: digitalWrite(8, HIGH); si no, LOW.
  6. ¿Lazo? Cerrado: mide continuamente y responde a lo que mide.

Tu casa

El termostato, la nevera, la cisterna del váter: todo lazo cerrado. La calefacción se lleva casi la mitad de la energía que gasta un hogar en España.

Los coches

Un coche actual lleva decenas de sensores. El ABS vigila la velocidad de cada rueda continuamente para que no se bloquee al frenar.

Taller: ejercicios sin fin

Cada bloque genera un ejercicio nuevo cada vez que pulsas «otro», con su solución paso a paso si te atascas.

En el código, mayúsculas y minúsculas dan igual aquí (en Arduino no: OUTPUT va en mayúsculas).

Cómo usar esto: haz cinco seguidos de cada bloque sin mirar la solución. Si encadenas cinco, ese tipo lo tienes. Si fallas dos veces lo mismo, vuelve a la teoría de arriba antes de seguir.
